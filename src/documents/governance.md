# 機密情報及び成果物取扱規程

東邦大学医学部IT部 
2026年8月2日制定

## 第1条（目的）

本規程は、東邦大学医学部IT部（以下「本団体」という。）における機密情報及び個人情報の適正な取扱い並びに本団体の活動を通じて創作された成果物の権利帰属及び利用条件を定め、情報漏えい及び権利関係に係る紛争を防止することを目的とする。

## 第2条（適用範囲）

1. 本規程は、本団体のすべての構成員に適用する。
2. 本団体への入会及び本団体が管理する機密情報へのアクセスには、本規程への同意を要する。
3. 本団体の構成員となる者は、民法上の成年者でなければならない。
4. 構成員が退会、卒業その他の事由により本団体を離れた場合であっても、本規程において退会等の後も存続すると定められた義務は、引き続き効力を有する。

## 第3条（定義）

本規程における用語の定義は、次の各号に定めるところによる。

1. 「機密情報」とは、本団体の活動に関連して構成員が取得し、閲覧し、又は知り得た一切の非公開情報をいう。
2. 「個人情報」とは、生存する個人に関する情報であって、氏名、学籍番号その他の記述等により特定の個人を識別できるもの又は他の情報と容易に照合することにより特定の個人を識別できるものをいう。
3. 「プロジェクト」とは、本団体の活動として実施する開発、研究、制作、運用その他の活動をいう。
4. 「成果物」とは、プロジェクト又は本団体の活動に関連して創作されたプログラム、ソースコード、ウェブサイト、設計書、仕様書、文書、画像、映像、音声、デザインその他の著作物をいう。
5. 「公開成果物」とは、本団体又は当該成果物の権利者による適正な手続を経て、不特定多数の者に公開された成果物をいう。
6. 「非公開成果物」とは、公開成果物以外の成果物をいう。
7. 「プロジェクト関係者」とは、当該プロジェクトの企画、設計、開発、制作、運用又は管理に実質的に関与した者をいう。
8. 「責任者」とは、本団体の部長、プロジェクト責任者その他本団体が指定する者をいう。
9. 「第三者」とは、本団体及び当該情報又は成果物を取り扱う権限を有するプロジェクト関係者以外の者をいう。

## 第4条（機密情報の範囲）

機密情報には、次に掲げる情報を含む。ただし、これらに限られない。

1. Google Driveその他のオンラインストレージに保存された非公開の資料及びデータ
2. GitHub Organizationその他のソースコード管理サービスにおける非公開リポジトリの内容
3. ソースコード、設計書、仕様書、構成情報、設定情報及び運用情報
4. ID、パスワード、APIキー、秘密鍵、アクセストークンその他の認証情報
5. サービス利用者名簿、構成員名簿その他の個人情報
6. 企画、会計、契約、運営及び意思決定に関する非公開情報
7. 開発中又は公開前の成果物
8. 本団体が第三者に対して秘密保持義務を負う情報
9. その他、その内容又は開示の状況から、非公開情報として取り扱うべきことが合理的に認められる情報

## 第5条（機密情報から除外される情報）

前条の規定にかかわらず、構成員が客観的資料によって次の各号のいずれかに該当することを証明できる情報は、機密情報に含まれない。

1. 取得時に既に公知であった情報
2. 取得後、構成員の責めに帰すべき事由によらず公知となった情報
3. 取得前から適法に保有していた情報
4. 秘密保持義務を負うことなく、正当な権限を有する第三者から適法に取得した情報
5. 機密情報を利用することなく独自に取得し、又は創作した情報
6. 本団体が外部への開示又は公表を明示的に承認した情報

## 第6条（機密情報の利用及び管理）

1. 構成員は、機密情報を本団体の活動又は担当するプロジェクトの遂行に必要な範囲内でのみ利用しなければならない。
2. 構成員は、本団体の事前の承認を得ることなく、機密情報を第三者に開示し、提供し、送信し、又は漏えいしてはならない。
3. 構成員は、機密情報の漏えい、滅失、毀損、不正利用又は不正アクセスを防止するため、必要かつ適切な安全管理措置を講じなければならない。
4. 構成員は、担当業務に必要な範囲を超えて機密情報を閲覧し、複製し、保存し、又は持ち出してはならない。
5. 構成員は、機密情報を外部の端末、アカウント、オンラインストレージその他の情報処理サービスに入力し、保存し、又は送信する場合、当該サービスの安全性及び利用条件を確認し、機密情報の漏えい又は目的外利用を防止するために必要かつ適切な措置を講じなければならない。
6. 構成員は、本団体から付与されたアカウント又は認証情報を第三者に使用させ、又は第三者と共有してはならない。
7. 本条に定める義務は、構成員が本規程に同意した時から発生し、退会、卒業その他の事由により本団体を離れた後も、期間の定めなく存続する。

## 第7条（個人情報の取扱い）

1. 構成員は、個人情報を、本団体が定める利用目的及び担当業務の遂行に必要な範囲内でのみ取り扱わなければならない。
2. 構成員は、担当業務に必要な範囲を超えて個人情報を閲覧し、取得し、複製し、持ち出し、又は利用してはならない。
3. 構成員は、個人情報を自己のポートフォリオ、履歴書、就職活動資料、研究発表、SNSその他の私的な目的に利用してはならない。
4. 構成員は、開示先との間に秘密保持契約その他の秘密保持義務が成立している場合であっても、個人情報を開示してはならない。
5. 個人情報を匿名化して利用する場合は、他の情報との照合を含め、特定の個人を識別することができない状態にしなければならない。
6. 法令又は裁判所の命令により個人情報の開示義務が生じた場合は、法令上必要とされる最小限の範囲に限り開示できる。
7. 本条に定める義務は、構成員が本団体を離れた後も、期間の定めなく存続する。

## 第8条（法令等に基づく開示）

1. 構成員が、法令、裁判所の命令又は権限を有する公的機関の適法な要請により機密情報の開示を求められた場合は、法令により禁止される場合を除き、可能な限り事前に責任者へ通知し、その指示を受けなければならない。
2. やむを得ない事由により事前に通知できない場合は、通知が可能となった後、遅滞なく責任者へ報告しなければならない。
3. 構成員は、前二項に基づき機密情報を開示する場合、法令上必要とされる最小限の範囲を超えて開示してはならない。

## 第9条（事故等の報告）

1. 構成員は、機密情報又は個人情報の漏えい、滅失、毀損、誤送信、不正利用若しくは不正アクセスが発生し、又はそのおそれがあることを認識した場合、直ちに責任者へ報告しなければならない。
2. 構成員は、被害の拡大防止、事実関係の調査、情報の回収若しくは削除、認証情報の変更その他本団体が実施する是正措置に協力しなければならない。
3. 構成員は、本団体の承認を得ることなく、事故等に関して第三者への説明又は公表を行ってはならない。ただし、法令に基づく場合を除く。

## 第10条（退会等に伴う措置）

構成員が退会し、卒業し、担当業務を離れ、又は本団体から求められた場合は、遅滞なく次に掲げる措置を講じなければならない。

   - 本団体から付与されたアカウント及びアクセス権限を返還すること
   - 自己の端末、アカウント又は記録媒体に保存した機密情報及び個人情報を削除すること
   - 本団体から貸与又は交付された機器、資料及び記録媒体を返還すること
   - その他、本団体が情報の保護に必要であると認める措置を講じること

## 第11条（成果物の権利帰属）

1. 成果物に係る著作権は、当該成果物を創作した著作者に帰属する。
2. 複数の者が共同して創作し、かつ各人の寄与を分離して個別に利用することができない成果物に係る著作権は、当該著作者全員に共有される。
3. 企画の提案、助言、連絡、進行管理、試験又は検証のみを行った者は、当該行為のみをもって著作者となるものではない。
4. 外部の団体又は個人が関与するプロジェクトについて別途契約又は合意がある場合は、当該契約又は合意を優先する。

## 第12条（本団体に対する利用許諾）

1. 成果物の著作者は、本団体に対し、本団体の活動、プロジェクトの運営、保守、改修、引継ぎ、教育、研究、記録及び広報に必要な範囲内で、当該成果物を利用することを許諾する。
2. 前項の利用許諾は、無償、非独占的かつ期間の定めのないものとする。
3. 本団体は、第1項の目的に必要な範囲内で、成果物を複製、翻案、修正、改変、統合、公表、公衆送信、展示又は配布できる。
4. 本団体は、第1項の目的に必要な範囲内で、本団体の構成員又は当該プロジェクトの業務を適法に受託した者に成果物を利用させることができる。
5. 著作者は、本条に基づく成果物の利用について、その目的及び態様が合理的な範囲内である限り、著作者人格権を行使しないものとする。
6. 本条に基づく利用許諾は、著作者が本団体を離れた後も存続する。

## 第13条（公開成果物の実績掲載）

1. 構成員は、公開成果物について、自己のポートフォリオ、履歴書、職務経歴書、就職活動資料、ウェブサイト、SNSその他の媒体に掲載し、又は言及できる。
2. 前項の掲載又は言及については、プロジェクトごとに別段の定めがある場合を除き、他のプロジェクト関係者の個別の承諾を要しない。
3. 構成員は、掲載又は言及に際し、次に掲げる事項を明示しなければならない。

   - プロジェクトの名称
   - 団体名「東邦大学医学部IT部」
   - 自己が担当した業務及び創作した部分
   - 複数人が関与した場合は、共同で制作又は開発した成果物である旨
4. 構成員は、成果物の全部を自己が単独で創作したと誤認させる表示をしてはならない。
5. 他のプロジェクト関係者の氏名、所属、写真、アカウント名その他個人を識別できる情報を掲載する場合は、あらかじめ当該本人の明示的な承諾を得なければならない。
6. 前項の承諾を得ていない場合は、「複数名による共同開発」その他個人を特定しない表示を用いなければならない。
7. 公開成果物に関連する情報であっても、一般に公開されていないソースコード、設計書、内部資料、管理画面、認証情報、個人情報その他の機密情報を掲載してはならない。

## 第14条（非公開成果物等の開示）

1. 構成員は、非公開成果物及び開発中の成果物を第三者に開示し、提示し、又は具体的に説明してはならない。
2. 前項の規定にかかわらず、就職活動、進学、研究活動その他自己の能力又は経験を説明する正当な目的があり、かつ次に掲げる要件をすべて満たす場合に限り、必要最小限の範囲で非公開成果物又は開発中の成果物について言及し、又は提示できる。

   - 開示先との間に有効な秘密保持契約又はこれと同等の秘密保持義務が成立していること
   - 開示先における利用目的及び閲覧権限を有する者が特定されていること
   - 開示先から第三者への再開示が禁止されていること
   - 開示する情報が当該目的の達成に必要な最小限の範囲に限定されていること
   - 法令、第三者との契約又はプロジェクトごとの取決めにより開示が禁止されていないこと
3. 口頭による一般的な秘密保持の約束は、前項第1号に定める秘密保持義務には該当しない。
4. 構成員は、可能な限り、開示先、開示日、開示目的及び開示した情報の範囲を記録しなければならない。
5. 本条の規定にかかわらず、個人情報、認証情報その他本団体が開示を禁止した情報を開示してはならない。
6. 本条は、非公開成果物の一般公開、再配布、譲渡又はライセンス供与を許諾するものではない。

## 第15条（成果物の再配布等）

1. 構成員が成果物について次に掲げる行為を行う場合は、あらかじめ当該行為に係る権利を有する者全員の承諾を得なければならない。

   1. 成果物又はその複製物を第三者に配布する行為
   2. ソースコードを公開リポジトリその他の媒体で一般に公開する行為
   3. オープンソースライセンスその他の利用許諾条件を設定する行為
   4. 成果物を販売し、譲渡し、貸与し、又は有償で提供する行為
   5. 第三者に成果物の改変、複製、再配布又は再利用を許諾する行為
   6. 成果物を他の団体、事業又はプロジェクトに転用する行為
2. 前項の承諾は、書面、電子メール、グループチャットその他承諾の内容を記録及び保存できる方法により取得しなければならない。
3. 前項の承諾を求める場合は、対象となる成果物、利用目的、提供先、公開又は配布の範囲、対価の有無及び適用する利用許諾条件を明示しなければならない。
4. 権利者の一部から承諾を得られない場合は、当該権利者が権利を有する部分を除外できる場合を除き、再配布等を行ってはならない。
5. 本条の規定は、第13条に基づく公開成果物の実績掲載には適用しない。

## 第16条（プロジェクトごとの特則）

1. プロジェクト関係者は、当該プロジェクトについて、次に掲げる事項を別途定めることができる。

   1. 成果物及び各構成員の担当範囲
   2. 著作者及び著作権その他の権利の帰属
   3. 公開の可否、公開範囲及び公開時期
   4. 適用する利用許諾条件
   5. 第三者への提供及び再配布の条件
   6. ポートフォリオその他への掲載条件
   7. プロジェクト終了後の運用、保守及び管理方法
2. 前項の取決めは、書面又はその内容を記録及び保存できる電磁的方法により行わなければならない。
3. プロジェクトごとの取決めと本規程が抵触する場合、機密情報及び個人情報の保護については、より厳格な定めを優先する。
4. 成果物の権利帰属又は利用許諾については、関係する権利者全員が明示的に合意したプロジェクトごとの取決めを優先する。

## 第17条（違反時の措置）

1. 構成員が本規程に違反し、又は違反するおそれがある場合、本団体は、違反の内容及び影響の程度に応じ、次に掲げる措置を講じることができる。

   1. 事実関係に関する報告又は資料の提出の要求
   2. 戒告又は厳重注意
   3. 情報、成果物又は掲載物の削除若しくは利用停止の要求
   4. アカウント又はアクセス権限の一時停止若しくは取消し
   5. プロジェクト又は本団体の活動への参加停止
   6. 退会の勧告又は退会処分
   7. その他、被害の発生若しくは拡大の防止又は原状回復に必要な措置
2. 緊急に情報漏えい、権利侵害その他の損害を防止する必要がある場合、本団体は、事前の通知を行うことなく、アクセス権限の停止その他必要な暫定措置を講じることができる。
3. 本団体は、本規程の違反により損害が生じた場合、法令に基づき損害賠償、差止め、原状回復その他必要な請求を行うことができる。

## 第18条（規程の改廃）

1. 本規程の改正又は廃止は、本団体の規約に基づく決定により行う。
2. 本団体は、本規程を改正し、又は廃止した場合、本団体が公式の連絡手段として指定するグループチャットに、次に掲げる事項を掲載することにより構成員へ通知する。

   - 改正又は廃止を行った旨
   - 改正後の規程の全文又はその閲覧方法
   - 改正又は廃止の概要
   - 効力発生日
3. 改正後の規程は、前項の通知において定める効力発生日から適用する。
4. 改正後の規程は、効力発生日以後に行われる行為及び情報の取扱いに適用し、改正前に適法に成立した著作権の帰属その他の権利関係を遡及して変更しない。
5. 著作権の譲渡、既存の利用許諾範囲の実質的な拡張その他構成員の権利又は義務に重大な変更を生じさせる改正については、グループチャットによる通知のほか、当該構成員の明示的な同意を得なければならない。
6. 構成員は、本団体が指定する公式グループチャットを適宜確認しなければならない。

## 第19条（準拠法及び合意管轄）

1. 本規程の成立、効力、履行及び解釈には、日本法を適用する。
2. 本規程に関して紛争が生じた場合は、東京地方裁判所又は東京簡易裁判所を第一審の専属的合意管轄裁判所とする。

## 第20条（協議事項）

本規程に定めのない事項又は本規程の解釈に疑義が生じた場合は、本団体及び関係者が、関係法令、各自の寄与並びに機密情報及び個人情報の保護を考慮し、誠意をもって協議の上、解決するものとする。

## 附則

1. 本規程は、2026年8月2日から施行する。
2. 本規程の施行前に創作された成果物の権利帰属については、当該成果物の創作時に成立した合意及び関係法令に従う。
3. 本規程の施行前から本団体が保有する機密情報及び個人情報についても、本規程の施行日以後は本規程を適用する。
